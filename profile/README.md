## Four Beats

1. **Name the tryout.** Give the Stampack Xpress die tryout a short title before you stamp on the press.
2. **Pin the live blanks.** Keep current work on Stampack Xpress sheet forming and leave unused dies aside.
3. **Read the sim.** Open Stampack Xpress stamping sim before you move a blank that already has a layout.
4. **Check the layout.** Read Stampack Xpress blank layout before you archive a tryout.
5. **Keep the pair.** Leave forming and sim on the same Stampack Xpress die tryout.
6. **Leave the toolroom ready.** Keep the blank aligned with Stampack Xpress sheet forming.
7. **Read the tryout again.** Open Stampack Xpress die tryout if the screen still looks crowded.
8. **Close the loop.** Clear finished tryouts so the next Stampack Xpress visit does not start with a search.

## First Questions

**Does Stampack Xpress replace every other program?**
No. Stampack Xpress sits beside the press list, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate Stampack Xpress profile.

**What should a new user try first?**
One small Stampack Xpress blank today, then the same stamping sim tomorrow.

**Does blank layout leave the die tryout?**
No. Stampack Xpress blank layout stays with Stampack Xpress stamping sim on that tryout.

**Is Stampack Xpress only for a finished die?**
No. Stampack Xpress can hold a single blank while the rest of the toolroom stays off the board.

**Does the press need a second file for the blank?**
No. Stampack Xpress keeps sheet forming and blank layout on this die tryout.

Yes. A named Stampack Xpress die tryout keeps the blank visible before the press starts.

**Can the sim stay with the layout?**

## Field Note

Stampack Xpress is easier to trust when the die tryout stays smaller than the folder it came from. A named tryout shows what is active, the blank pins show what you will review today, and the closing note tells the next person which layout changed.

The same loop fits a single blank, a short sim, or a toolroom shared by two people. Open the last Stampack Xpress die tryout, finish one blank layout, and leave fewer untried press setups than you found.

A review should not have to guess which blank belongs to the open sim. Keep that pair together inside Stampack Xpress.

Other programs stay where they are. Stampack Xpress only holds the sheet forming, the stamping sim, and the handoff.

The tryout is short on purpose: not a copy of every die file, only the path back to the blank that is still open.

## One Real Pass

Pick a die that already has a name. Open it in Stampack Xpress, keep only that blank on sheet forming, and finish one stamping sim you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different press and leave it out of this Stampack Xpress die tryout.

A pass is done when that blank is tried on screen and the extra dies are no longer in the way.
